# VR-Prototyp Jugendfeuerwehr

VR-Prototyp zur Brandbekämpfung für die **Meta Quest 2**, entstanden im Rahmen einer Masterarbeit an der **Universität Potsdam**.

## Funktionen

- Hauptmenü, Tutorial und Brandszenario
- Zwei Feuerlöschertypen (Auflade- und Dauerdruckfeuerlöscher) mit Sicherungsstift, Schlauch und Füllstandsanzeige im Sichtfeld
- Brandklassen A, B, C, D und F
- Dynamische Brandausbreitung
- Didaktische Wissensvermittlung bei falscher Löschtechnik und falscher Feuerlöscherwahl

## Installation

Installation der APK über Meta Quest Developer Hub auf die Quest (Entwicklermodus aktivieren) installieren. 
Start über Bibliothek -> Unbekannte Quellen.

Unity `6000.2.10f1` URP Meta XR SDK
